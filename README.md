# Graphite Pools Professionals website

A single-page site for Graphite Pools Professionals (Montague, Boksburg), with privacy and terms pages.

- `index.html` is the website; `privacy.html` and `terms.html` are the legal pages.
- `js/scene.js` is the 3D pool. It builds itself in five stages (dig, shell, coping and finish,
  paving, fill) as you scroll through "How a new pool goes in", and has a day/night pool-light mode.
- `js/main.js` connects the scroll position, the pool-light button, the photo viewer and the quote form.

## Preview locally
The 3D scene uses JavaScript modules, so the site has to be served rather than opened as a file:

    python -m http.server 5530

Then open http://localhost:5530. Add `#debug` to the URL to expose `window.__pool` in the console.

## 3D assets
`assets/3d/` holds CC0 assets from Poly Haven (polyhaven.com): the "Pretoria Gardens" panorama and HDRI,
and the stucco and concrete normal/roughness maps. Paver, charcoal tile, soil and stacked-stone textures are
generated by `python tools/make-textures.py` (needs Pillow, numpy and opencv-python).

## Icons and link preview
`python tools/make-brand.py` rebuilds the favicon, app icons and `assets/brand/og-image.jpg` from the logo.

## Hosting and domain
Hosted on GitHub Pages from the `main` branch: https://obsidianstudiodesigns.github.io/GraphitePools/
(repo: https://github.com/obsidianstudiodesigns/GraphitePools). Push to `main` and Pages rebuilds.

Canonical links, the link preview, `sitemap.xml` and `robots.txt` use that Pages address. If the client gets
their own domain, add a `CNAME` file and replace `https://obsidianstudiodesigns.github.io/GraphitePools/`
in `index.html`, `privacy.html`, `terms.html`, `sitemap.xml` and `robots.txt`.
